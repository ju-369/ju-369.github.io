Descripción

Gestión de Biblioteca es una aplicación web completa para el control de una biblioteca, desarrollada durante el bootcamp de Java Spring. Permite administrar el inventario de libros.

El sistema está construido con Java EE y MySQL, ofreciendo una interfaz web moderna que consume el backend. Incluye autenticación de usuarios.

Características Principales

Inventario de Libros

CRUD completo con ISBN, autor y categoría.

Préstamos y Devoluciones

Registro con fechas límite y estado.

Búsqueda

Consulta por título, autor o categoría.

Gestión de Usuarios

Registro y autenticación de bibliotecarios.
