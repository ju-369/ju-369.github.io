Descripción

Sistema de Tareas en Terminal es una aplicación de línea de comandos desarrollada en Java para la gestión eficiente de tareas diarias. Permite crear, listar, actualizar y eliminar tareas directamente desde la terminal.

Utiliza Java SE y Programación Orientada a Objetos como base. Las tareas se organizan por estados (pendiente, en progreso, completada) y admiten filtros por prioridad, categoría y fecha de vencimiento.

Características Principales

CRUD por Terminal

Crear, leer, actualizar y eliminar tareas.

Filtros y Búsqueda

Por estado, prioridad y categoría.

POO

Programación Orientada a Objetos para la gestión de tareas.

Prioridades

Alta, media y baja para organizar tareas.

Comandos Principales

ADD tarea add "Descripción" --prioridad=alta Crear nueva tarea
LIST tarea list --estado=pendiente Listar tareas filtradas
UPDATE tarea update {id} --estado=completada Actualizar estado
DELETE tarea delete {id} Eliminar tarea
SEARCH tarea search "palabra" Buscar por descripción
