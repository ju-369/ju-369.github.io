Descripción

Gestión Educacional es una aplicación web desarrollada durante el bootcamp de Java Spring para la gestión integral de instituciones educativas. Permite administrar estudiantes (habilitado hasta aqui durante el bootcamp), cursos y calificaciones desde una interfaz moderna y fácil de usar.

El backend está construido con Spring Boot y maneja la lógica de negocio y persistencia en MySQL, mientras que Thymeleaf genera las vistas dinámicas del lado del servidor.

Características Principales

Gestión de Estudiantes

CRUD completo con datos personales y académicos.

Gestión de permisos

Control de acceso y privilegios por usuario.

Api REST

Endpoints para la comunicación con el backend.

Panel de Administración

Administración de los estudiantes.
